# GRP-002 — Documents have an incoming reference

> Category **GRP** (graph integrity) · Scope **project** · Default severity **warning** · Fixable **no** · [Rules index](README.md) · [Configuration](../configuration.md)

## What it checks

Every document in the repository must have at least one **incoming reference** — some other document that links to, imports, or otherwise points at it — unless it is declared an **entry point**. GRP-002 reads the shared [ContextGraph](../context-graph.md) and reports each node whose in-degree is zero, catching orphaned files that nothing else reaches.

In-degree counts every kind of reference edge into the document: plain links, in-page anchor links (a link to `detail.md#section` counts as reaching `detail.md`), image references, and eager `@import` directives. When [`settings.idRef`](../configuration.md) is configured, `id-ref` edges count too — a document referenced only by its ID from elsewhere is _not_ an orphan.

Because this rule reasons about relationships _between_ files, its scope is `project`: it runs once over the whole corpus. Findings are anchored at the top of the orphaned file.

## Options

| Option | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `entryPoints` | `string[]` | no | `["README.md", "CLAUDE.md", "AGENTS.md", "index.md"]` | Glob(s) for documents allowed to have no incoming reference (roots like `README.md`, `index.md`). |
| `files` | `string[]` | no | all included | Glob(s) narrowing which orphaned files this rule instance reports. |
| `exclude` | `string[]` | no | — | Glob(s) removing files from this rule instance's reporting. |

**The default `entryPoints` are matched at any depth.** They contain no `/`, so under the [glob semantics](../configuration.md#glob-semantics) each behaves as `**/<name>` — a per-package `packages/x/AGENTS.md` or a `docs/README.md` is exempt just as the root files are. Without this default the rule flagged a repository's own canonical roots, which on a real corpus was most of its output.

**A `entryPoints` you write _replaces_ the default; it does not extend it.** This is deliberately the opposite of the top-level [`exclude`](../configuration.md#what-is-excluded-before-you-write-anything), which extends: there, silently dropping a default re-opens `node_modules`, while here the value is a list of roots you know, and extending would make "do not exempt `README.md`" impossible to express. To keep the defaults and add to them, list them yourself.

> **Note:** the shared ContextGraph always covers the whole corpus, so `files`/`exclude` narrow _which orphans get reported_, not which documents the graph sees. A file excluded from reporting still contributes its outgoing edges to other documents' in-degree. Route resolution likewise comes from [`settings.siteRouter`](../configuration.md#settingssiterouter) through that shared graph — there is no per-rule `siteRouter` option here.

## Example

### Config

```jsonc
{
  "rules": [{ "rule": "GRP-002", "options": { "entryPoints": ["index.md"] } }],
}
```

### Passes

```md
<!-- index.md -->

See [a](a.md).

<!-- a.md -->

# A
```

`index.md` is a declared entry point (no incoming reference required); `a.md` is reached from it.

### Fails

```md
<!-- index.md -->

See [a](a.md).

<!-- a.md -->

# A

<!-- orphan.md -->

# Orphan
```

→ GRP-002 reports **``orphan.md has no incoming references; link it from another document or add it to GRP-002's `entryPoints`.``** — nothing points at `orphan.md`, and it is not an entry point.

### Anchor links still count

```md
<!-- index.md -->

See [a](a.md).

<!-- a.md -->

See [the detail](detail.md#detail-heading).

<!-- detail.md -->

## Detail Heading
```

→ No finding: the anchor link from `a.md` reaches `detail.md`, giving it an incoming reference.

## Notes

- **Scope:** `project` — evaluated once over the whole corpus, not per file.
- **Default severity is `warning`**, not `error` — orphaned files are often intentional (drafts, templates), so declare them as `entryPoints` to silence the finding.
- **`README.md`, `CLAUDE.md`, `AGENTS.md`, and `index.md` are exempt at any depth unless you set `entryPoints` yourself**, which replaces the whole list. See the Options table.
- **Edges considered:** links, anchors, images, `@import`, and `id-ref` (the last only when `settings.idRef` is set). See [Context graph](../context-graph.md).
