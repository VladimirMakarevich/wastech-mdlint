# CTX-005 — Images have alt text

> Category **CTX** (content quality) · Scope **document** · Default severity **warning** · Fixable **no** · [Rules index](README.md) · [Configuration](../configuration.md)

## What it checks

CTX-005 reports an image with no alt text, such as `![](diagram.png)`. A model reading the documentation does not see the image, so its alt text is all of it that reaches the context; an image without one is a gap in what the model reads.

An image is reported when its alt text is empty or made only of whitespace:

- **Empty:** `![](a.png)`.
- **Whitespace only:** `![ ](a.png)`, a non-breaking or ideographic space, or an alt that is only a line break. Whitespace gives a reader nothing either.

The alt text is judged as it renders: escapes and entities are decoded and emphasis or inline code is reduced to its text, so `![*diagram*](a.png)` has the alt `diagram` and is not reported.

- **Inline and reference images** are judged alike. `![][ref]` is reported; `![diagram][ref]`, `![diagram][]` and a shortcut `![diagram]` with a matching definition are not. A reference image takes its alt from its own brackets, never from the definition's title.
- **Images inside links** are judged too: `[![](badge.svg)](https://example.com)` is reported, because the alt is still all a model gets of the image, whatever the link says.
- Images are checked wherever they appear: in paragraphs, headings, list items and table cells. Image syntax inside a fenced code block or inline code is not an image and is never reported.

What CTX-005 does not check:

- **Raw HTML `<img>`** is not parsed as an image, so `<img src="a.png" alt="">` is not reported.
- **The quality of the description.** Only the presence of text is checked: punctuation-only alt such as `![-](a.png)`, or a filename such as `![a.png](a.png)`, is not reported.
- **An undefined reference** such as `![][missing]` is not an image at all; [REF-007](REF-007.md) reports it.

There is no marker for a purely decorative image in Markdown, so CTX-005 cannot tell one apart. Silence it with an inline disable or leave the file out with `exclude`.

## Notes

- **Scope:** `document` — evaluated per file, independent of other files.
- **Not fixable:** writing a description is a judgment call, so CTX-005 reports rather than rewrites.
- **Default severity is `warning`:** this is writing hygiene, and the rule is meant to be enabled without options.
- `init` does not propose CTX-005; add it to your config yourself.
- A finding can be silenced with an inline `<!-- wastech-mdlint-disable-next-line CTX-005 -->` on the line before the image.
