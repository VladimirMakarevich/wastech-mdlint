# SEC-006 — No emphasis used as a heading

> Category **SEC** (sections) · Scope **document** · Default severity **warning** · Fixable **no** · [Rules index](README.md) · [Configuration](../configuration.md)

## What it checks

SEC-006 reports a paragraph made only of bold or italic text, such as a line `**Installation**`, that stands in for a heading. It looks like a heading on the page, but to everything that reads the outline it is an ordinary paragraph:

- [SEC-001](SEC-001.md) and [CTX-001](CTX-001.md) cannot find it as a section.
- A `section` option (in TBL-\*, SEC-\*, CTX-\* or a `custom` rule) cannot name it.
- `slice` cannot cut at it, and it gets no anchor to link to.

The semantics follow markdownlint's MD036. A paragraph is reported when all of these hold:

1. It is a top-level paragraph. Emphasis inside a list item, a blockquote, a footnote or a table cell is not reported.
2. Its only content is one bold (`**x**`, `__x__`) or italic (`*x*`, `_x_`) run.
3. That run holds plain text only. Nested formatting (`***x***`), inline code (``**Install `npm`**``) or a link (`**[x](y.md)**`) inside it is not reported.
4. The text fits on one line. A bold run wrapped over several lines is an emphasised sentence, not a title.
5. The text does not end with a character from `punctuation`. By default that is `.,;:!?` and the full-width `。，；：！？`, so `**A bold sentence.**` and `**Note:**` are not reported.

A setext heading whose text is bold (`**Title**` underlined with `---` or `===`) is a real heading, so it is not reported.

### Overlap with SEC-004

A document whose first block is `**Title**` is reported twice on line 1: by [SEC-004](SEC-004.md)'s `title` check (the document does not start with a title) and by SEC-006 (emphasis used instead of a heading). The two findings describe different defects, and turning the paragraph into `# Title` fixes both.

## Options

| Option | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `punctuation` | `string` | no | `.,;:!?。，；：！？` | Characters that, as the last character of the text, mark it as a sentence or lead-in and exempt it. Each character is one entry. `""` exempts nothing, so even `**Note:**` is reported. |
| `files` | `string[]` | no | all included | Glob(s) narrowing which files this rule instance applies to. |
| `exclude` | `string[]` | no | — | Glob(s) removing files from this rule instance. |

## Example

### Config

```jsonc
{
  "rules": [{ "rule": "SEC-006" }],
}
```

### Passes

```md
# Guide

## Installation

**This step is required.**

- **Tip** inside a list
```

### Fails

```md
# Guide

**Installation**
```

→ SEC-006 reports line 3: `Emphasis used instead of a heading: "Installation".`

## Notes

- **Scope:** `document` — evaluated per file, independent of other files.
- **Not fixable:** choosing the heading level is a judgment call, so SEC-006 reports rather than rewrites.
- **Default severity is `warning`:** this is outline hygiene, and the rule is meant to be enabled without options.
- A finding can be silenced with an inline `<!-- wastech-mdlint-disable-next-line SEC-006 -->` on the line before the paragraph.
