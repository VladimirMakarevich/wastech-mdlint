# REF-007 — Reference links and images use a defined label

> Category **REF** (references) · Scope **document** · Default severity **error** · Fixable **no** · [Rules index](README.md) · [Configuration](../configuration.md)

## What it checks

Every reference-style link and image must use a label that has a definition in the same file. REF-007 reports each reference whose label has no matching `[label]: <target>` line, anchored at the opening `[` (or at the `!` of an image), and names the label.

Markdown does not treat an undefined reference as an error. `[text][missing]` with no `[missing]: …` definition is not a link at all: it renders as the literal brackets, and no other rule sees it, because there is no link to resolve. REF-007 is what makes that mistake visible.

Three reference forms exist:

- **Full** — `[text][label]` and `![alt][label]`. Always checked.
- **Collapsed** — `[label][]` and `![label][]`. Always checked.
- **Shortcut** — `[label]` and `![label]`. Checked only when `includeShortcut` is `true`.

Shortcut references are off by default because a bracketed word in prose — `[sic]`, `[WIP]`, `[x]` — looks exactly like one. The full and collapsed forms are unambiguous attempts at a link, so reporting them raises no false positives on ordinary text.

Labels match their definition the way CommonMark matches them: case-insensitively, with runs of spaces, tabs and line breaks treated as one space and leading or trailing whitespace ignored. So `[text][My Label]` is satisfied by `[my   label]: guide.md`.

## Options

| Option | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `includeShortcut` | `boolean` | no | `false` | Also report shortcut references (`[label]`, `![label]`) whose label has no definition. Off by default because bracketed words in prose are indistinguishable from them. |
| `files` | `string[]` | no | all included | Glob(s) narrowing which files this rule instance applies to. |
| `exclude` | `string[]` | no | — | Glob(s) removing files from this rule instance. |

## Example

### Config

```jsonc
{
  "rules": [{ "rule": "REF-007" }],
}
```

### Passes

```md
See the [setup guide][Setup] and the ![architecture][arch].

[setup]: docs/setup.md
[arch]: images/architecture.png
```

### Fails

```md
See the [setup guide][missing] and the ![architecture][gone].
```

→ REF-007 reports two findings on line 1: `Reference "[missing]" has no definition, so it renders as literal text; add a "[missing]: <target>" definition or correct the label.` at column 9, and `Image reference "[gone]" has no definition, so it renders as literal text; add a "[gone]: <target>" definition or correct the label.` at column 40. Each finding's `data` carries `label`, `kind` (`link` or `image`) and `referenceType` (`full`, `collapsed` or `shortcut`).

## Notes

- **Scope:** `document` — evaluated per file. A definition must be in the same file as the reference, as Markdown requires.
- **Never read:** code spans, fenced and indented code blocks, inline and block HTML, autolinks, and frontmatter. Brackets written with escapes (`\[`) or HTML entities (`&#91;`) are not reference syntax either.
- **Never reported:** footnote calls such as `[^1]` (also written `[^1][]`), and GitHub alert markers such as `> [!NOTE]`, in any mode. A full reference whose label starts with `^`, such as `[text][^missing]`, is not a footnote call and is reported.
- **Index notation in prose is reported.** `matrix[i][j]` written as plain text is a full reference with the label `j` as far as Markdown is concerned, and it renders as text only because `j` happens to have no definition. Put it in a code span — `` `matrix[i][j]` `` — which also stops it from turning into a link the day someone adds a `[j]:` definition.
- **Not fixable.** There is no target to invent, so the rule leaves the repair — adding the definition or correcting the label — to the author.
- **No graph edge.** An undefined label has no target, so it adds nothing to the context graph.
- **Not proposed by `init`.** A corpus can only show evidence for this rule by containing an undefined label, which is itself a finding, so `init` never adds it to a draft config. Enable it by hand.
- **`files`/`exclude`** narrow which files this rule instance applies to.
